          Step 1 of 3 · Your starting point

          What does your study look like?

          This example compares two conditions. Each learner sees words in both conditions; each word appears in both conditions across learners. Different design? Review the structure. Including known words? Define the scores.

          Why both counts matter

          A condition may work differently for different learners, and differently for different words. Adding learners addresses the first source of variation; adding words addresses the second.

          Review or change the variation assumptions Start with example values

          These values describe how much the difference between the two conditions varies. Larger values mean more variation. The starting values are examples for exploration, not estimates or recommended settings for your study.

          Checking the box removes the memory component from this calculation. It assumes that component is fully accounted for; simply measuring memory does not establish this. Uncertainty in estimating the moderator effect is not included.

          How do I choose values if I am unsure?
          1. Use comparable evidence when available. Look for slope SDs from a pilot or prior study with a comparable task, the same outcome model and the same condition coding. These inputs use the latent logit scale; raw-score SDs, accuracy percentages and standard errors are not substitutes.
          2. Explore uncertainty. Without suitable estimates, use the example to learn the tool. Then try lower and higher plausible values, changing one assumption at a time. There is no universal cutoff for a small or large value.
          3. Check whether the conclusion changes. Compare the same study sizes again. If the preferred expansion changes, the choice depends on the assumptions; seek better evidence before committing. Record the values you tried and why.

            Declare every facet explicitly

            A blank parent means crossed or top-level. “Condition varies within” determines whether a facet-specific condition slope is estimable.

            Facet ID Parent Levels Condition varies within Generalization target Model role Dependence Slope Remove
            Add fixed predictors and their random slopes

            The base fixed model contains an intercept and condition. Add variables by name and type; a categorical variable contributes one fewer coefficient than its levels. This specifies a model, not its precision or power.

            For each predictor, declare the facet IDs within which it varies. Request a slope only within those random facets. A condition interaction also adds its interaction slope in requested facets; verify both variables vary and that the actual design supports their interaction. Added slopes use the facet’s diag/us structure, or diag when its condition slope is None.

            The facet role “Fixed” means fixed context in this structural audit; it does not add a predictor or adjust for that facet. Added predictors do not change the SD assumptions in the two-facet projection: they require a separate analysis.

            Plan an offline power simulation in R

            Generate and refit binary responses for two counterbalanced conditions, with crossed learners and words. This downloads an R program; no simulation runs in your browser. These counts are independent of the curve and scoring examples. Conditions use −0.5/+0.5 coding; effect inputs are logit coefficients, not percentages. Start with a short run to check execution, then increase replications for Monte Carlo precision.

            Random-effect distributions

            Zero-mean normal random effects. Only terms in the selected model are generated; SD controls for absent slopes are inactive. Added slope SDs apply to each added numeric or categorical-contrast coefficient, including its requested interaction. For diag/none use zero correlation; us allows one common generating correlation while the fitted model estimates a full covariance matrix.

            Known targets and feedback-only fillers

            Known target status is sampled independently of ability, difficulty and condition. To generate known targets, select initially unknown targets in the score definition; they are excluded from the fitted model. This simple screening assumption does not model informative selection. Fillers enter feedback scores only; their effect on motivation, fatigue or exposure is not modeled.

            Added numeric predictors are independent normal draws; categories are equiprobable with level 1 as reference. Their within-facet declarations determine learner-, word- or response-level sampling. This is not a repeated-time design or a correlated-covariate generator. Values below are separate from the curve's memory-adjustment assumption.

                How to interpret these results
          
                Wilson intervals describe Monte Carlo uncertainty in the displayed rates; they are not intervals for the model coefficient. Coverage measures how often the model's 95% coefficient interval contains the generating coefficient. Monte Carlo SE can be zero when every usable replication has the same outcome; the Wilson interval still reflects finite simulation size.
                
          
                Excluding singular fits changes the subset being summarized. Neither subset corrects bias caused by unsuccessful fits. Inspect individual warnings, estimates, eligibility and feedback scores in replications.csv, and the generating assumptions in assumptions.R. This summary does not identify the full design or model.
                
          
                Run the tested coefficient at zero to examine Type I error under the same nuisance effects. Compare plausible assumptions before making a design decision. Independent known-word screening and feedback-only fillers do not model a motivation effect.
